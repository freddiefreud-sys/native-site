# Native: native-site

The public front door for Native. One page: what Native is, the three plans and a brief form.

- The whole site is one file: `index.html`.
- The brief form sends to WhatsApp or email. It stores nothing.
- Before it works, edit the two lines marked `EDIT ME` near the bottom of `index.html`.
- While this is a pilot, the page is hidden from Google. Delete the `robots` line in `index.html` when you are ready to be found.

This repo is public. Never put client names, brand kits or briefs here. Those live in the private `native-os` repo.
